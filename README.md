# 🏭 방치형 공장 타이쿤

클릭으로 돈을 벌고, 기계로 자동 생산하는 방치형(Idle) 공장 경영 게임입니다.
외부 라이브러리 없이 단일 HTML 파일로 동작합니다.

## 🎮 플레이 방법

1. **🔨 생산하기** 버튼을 눌러 돈을 법니다 (클릭할 때마다 돈 획득)
2. 번 돈으로 **기계 6종**을 구매하세요 — 기계는 자동으로 초당 수익을 냅니다
   - 🏭 컨베이어 → 🤖 로봇팔 → 🖨️ 3D프린터 → ⚡ 용접기 → 🚚 AGV → 🧠 AI검사기
   - 같은 기계를 많이 살수록 가격이 1.15배씩 오릅니다
   - 구매 단위를 ×1 / ×10 / 최대로 바꿔 한 번에 많이 살 수 있습니다
3. **업그레이드 9종**으로 효율을 높이세요
   - 💪 손가락 강화: 클릭 수익 ×2 (10단계)
   - 🏗️ 공장 자동화: 전체 생산 +50% (10단계)
   - 🌙 24시간 가동: 오프라인 보상 효율 증가 (2단계)
   - 기계 6종 각각의 효율 ×2 개조 (일회성)
4. 게임을 꺼놔도 공장은 돌아갑니다! 다시 접속하면 **오프라인 보상**(최대 8시간)을 받을 수 있어요
5. 공장 바닥에 구매한 기계 아이콘이 하나씩 늘어나는 재미를 즐겨보세요

## 💾 저장

- 5초마다 + 창을 닫을 때 자동 저장됩니다 (브라우저 localStorage)
- 🗑 "처음부터 다시 시작" 버튼으로 기록을 초기화할 수 있습니다 (확인 후 삭제)
